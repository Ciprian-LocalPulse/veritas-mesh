# Support Veritas Mesh

**Veritas Mesh** is independent, self-funded, public-interest research founded and led by **Ciprian Ştefan Pleşca**, with no corporate, institutional, or government backing.

Funding directly determines how much time can go into specification rigor, formal verification, and independent security audits — the parts of this project that are slow, unglamorous, and absolutely non-negotiable for something intended to be trusted by banks, hospitals, and public institutions.

## What Contributions Fund

Contributions directly support the continued development and implementation of Veritas Mesh, including:

* Time spent on formal specification and TLA+ modeling (Phase 1 of the [Roadmap](ROADMAP.md))
* Independent third-party security audits (Phase 4)
* Infrastructure, including CI, documentation hosting, and the attestation mesh testnet once it exists
* Continued protocol development and implementation
* Eventually, compensating dedicated maintainers for specific subsystems

## Funding Transparency

Veritas Mesh is an independently developed research project.

Financial support is intended to fund:

**Research → Specification → Formal Verification → Implementation → Security Auditing → Maintenance**

Contributions do not purchase ownership of the project, control over the specification, or preferential treatment.

The project's technical direction remains independent.

## Non-Financial Contributions
