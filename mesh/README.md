# `mesh/` — Attestation Mesh Network (Go)

**Status: not started.** See [Project Status](../README.md#project-status) and [Roadmap](../ROADMAP.md) Phase 5.

## Intended scope

Per the [whitepaper](../whitepaper/Veritas_Mesh_Whitepaper.md) §6.4: a peer-to-peer network layer for publishing and retrieving attestations among institutions, auditors, and regulators, designed for high concurrency and partition tolerance. This is deliberately one of the last components on the roadmap — it depends on a stable attestation format from `core/`, which does not exist yet.
